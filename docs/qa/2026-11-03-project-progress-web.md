# 内部交互进度网页验收

日期：2026-11-03（Asia/Shanghai）。范围：本地内部文档页面，不涉及商店前台、Shopify 数据、凭据、CI/CD 或生产部署。

## 实现

- [网页](../project-progress.html)参考用户指定的 GEOly 路线图形式：米白底、阶段线路、任务方块、状态图例和当前位置。桌面阶段顺序沿线路 1→2→3→4→5→6，手机按顺序纵向展示。
- 六阶段、14 项任务均根据已有对齐/修复记录整理；保留历史验证日期，未完成任务日期待定。不能将“本地已验证”当作已发布。
- 支持阶段选择、点击任务定位并展开详情、原生键盘开合、任务搜索与状态组合筛选、空结果提示、近期动态和验收链接。
- HTML/CSS/JavaScript 为一个独立文档，无外部依赖，不读取 `.env`，不连接店铺 API、不导入商店构建。页面和 Markdown 记录需手动同步，不声称实时更新或在线修改项目状态。
- `scripts/serve-project-progress.mjs` 仅监听 `127.0.0.1:4174`，只提供明确列出的页面与 Markdown 验收文档；启动命令与维护入口见 README。也可直接打开 HTML，但此时不使用 HTTP 响应头。

## 验证结果

- 浏览器桌面 `1440×1000` 与手机 `390×844` 实际查看中文、箭头等字符，未见乱码；手机文档宽度 390px，无横向溢出。颜色之外保留状态文字及任务编号；44px 任务点击区、可见焦点和减少动效选项已实现。
- 实际点击阶段和任务，切换并自动展开对应内容；同一任务链接再次点击仍可操作。任务摘要聚焦后 Enter 可关闭并重新打开，摘要保留正常 Tab 焦点。
- 搜索“弹窗”并筛选“本地已验证”仅显示 T06；无匹配词显示 0 项与空结果提示。近期动态及验收视图可切换，四个来源文档请求均为 200。
- 六阶段、14 个任务方块和五条阶段连接线数量核对；完成数量从任务状态计算，不填虚构百分比或工期。
- 新服务命令语法与页面内联脚本语法/ESLint 检查通过；项目 lint 退出 0，保留原有两个脚本正常成功输出的 `no-console` 警告。
- HTTP 实测 HTML 为 `text/html; charset=utf-8`，验收 Markdown 为 `text/plain; charset=utf-8`，均含 `X-Robots-Tag: noindex, nofollow`。`.env`、项目根文件、脚本路径及穿越路径返回 404；POST 返回 405。服务仅本机监听。
- 正常页面重新加载后浏览器控制台无错误/警告；故意请求拒绝路径时的预期 404 不算页面运行错误。
