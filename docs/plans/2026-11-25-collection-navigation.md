## Shopify 与前台的数据边界

- Shopify 负责商品、变体、价格、库存、媒体、已发布集合和托管结账。Hydrogen 的商品页通过 Storefront API 按 handle 读取标题、描述、图片、变体售价、可售状态和公开的技术规格元字段。只改已有读取字段时，无需推送代码；缓存、发布渠道、市场和访问权限会影响何时、在哪里可见。详情页当前显示可售/售罄，不承诺渲染实际库存数字。
- 分类展示、栏目布局、代码管理的导航名单及新增元字段的显示逻辑由前端代码控制，后台编辑本身不改这些布局。要让线上显示本次本地改版，需要部署对应 Hydrogen 版本；推送 GitHub 和 Oxygen 正式发布是两件事。
- 此工作区以远程 `e7a9c0a` 为基线。本轮用同一 iPhone 18 Pro 详情地址核验 `localhost:3001` 和正式站均返回 200、显示相同商品标题及 USD 2.40；只读检查，未改后台商品或配置。
