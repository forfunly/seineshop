# 全站 SEO 详细规范

网站建设、内容、模板、路由、商品及上线验收涉及本规范时必须读取；适用于整个网站。

## 全站 SEO 规范

- 用户要求适用于**整个网站**，覆盖现有页面和后续新增页面、所有模板与组件、前后端代码、路由与信息架构、商品与集合数据、多语言、导航与内链、媒体、sitemap、robots 和部署后的 HTTP 响应。SEO 是全站开发及验收要求，不是单独某个页面的优化任务。
- 以 Google Search Essentials、Google Search Central 的技术要求、电子商务、JavaScript SEO、结构化数据及多语言文档为依据；实施具体功能时查阅相关最新官方要求。参考 TVCMALL 的结构与写法时同时满足本站 SEO 规范，不能复制来源站 canonical、品牌身份或不属于本站的内容与承诺。
- 可索引页面通过服务端渲染提供有效的主要内容、标题、描述和链接；检查初始 HTML 与浏览器渲染结果。使用语义化 HTML、清晰的标题层级和有真实 href 的可抓取链接，避免仅靠点击事件或客户端交互暴露重要内容。
- 每类页面按实际内容配置准确、可区分的 title、meta description 和主标题；使用稳定、清晰的 URL、正确的 HTTP 状态码与绝对 canonical。路由迁移时建立合理的永久重定向，避免软 404、重定向链、重复 URL 和模板生成的空白页。
- 明确不同页面的索引策略：商品、集合和有价值的内容页按业务需要开放；购物车、账户、站内搜索、筛选和排序组合等按用途控制索引与抓取，防止无限参数 URL。分页提供可抓取的分页链接和符合各页内容的 canonical，不能一律指向第一页。robots.txt 的 Disallow 不代替 noindex；需要搜索引擎读取 noindex 时不得同时阻断抓取。预览与测试环境保持访问保护并配置适当的禁止索引措施。
- sitemap 使用有效 UTF-8 XML，仅列出拟索引、公开可访问、返回 200 的规范 URL，排除重定向、404、noindex 及受保护页面。随真实商品、集合和内容变化更新；lastmod 反映页面有意义的实际修改，不伪造为每次请求时间。单文件遵守 50,000 URL 和未压缩 50 MB 上限，超限使用 sitemap index；在 robots.txt 声明正式 sitemap 地址。
- 多语言页面使用实际语言内容、正确的 HTML lang、自指 canonical 和相互对应的 hreflang；语言/地区代码与真实市场配置一致，按需使用 x-default。不可把所有译本 canonical 到同一语言，也不能为没有实际内容的语言或市场批量建页。
- 按页面事实和 Google 支持的类型实现结构化数据，例如 Product、商品变体、Offer、BreadcrumbList 和 Organization；价格、币种、库存、图片、URL 与用户可见内容保持一致。不得虚构评价、评分、折扣、配送或售后信息；按适用的 Google 富媒体搜索要求验证。
- 全站导航、分类和上下文内链帮助用户及爬虫发现重要页面，避免孤立页。商品描述、分类说明和其他内容真实、有用且与本站业务一致，不通过关键词堆砌、批量低价值页或隐藏内容获取排名。图片提供合适的 alt、尺寸及响应式资源，装饰图使用空 alt；重点检查移动端可用性、布局稳定性及 Core Web Vitals，避免关键内容被交互或资源加载阻断。
- SEO 验收同时检查模板代表页和全站 URL 一致性：抓取与索引规则、初始 HTML、metadata、canonical/hreflang、内链、结构化数据、sitemap、状态码、重定向、实际 Content-Type 和多语言编码显示。上线后以真实生产域名复查，按可用权限结合 Search Console 和官方验证工具；本地构建通过不能替代线上验收。记录已验证项、缺口及证据，不把写入规范或 sitemap 提交描述为已收录、已获排名或已完成全站 SEO。
