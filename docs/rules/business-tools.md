- 浏览器登录、多因素验证和安全挑战由用户完成；不得通过提取浏览器 Cookie、会话或未公开安装接口绕过授权流程。
- Reviews 和 B2B 的店面密钥相互独立；浏览器公钥限制真实 Origin，私钥只保存在获授权的服务端配置中。创建或变更密钥与 `.env` 前按根规则确认具体范围，不在文档、聊天、日志或构建中记录私钥。
- 分别记录“已选用”“后台已安装”“Headless 已接入”“生产已验证”；安装成功不能代替前台接入验收。未见后台成功状态时只写“待安装/未核实”。

## Hydrogen 接入要求

### Customerssay 评价

- 支持现成 JS 组件、自定义 API 界面和服务端渲染；结合现有 Hydrogen 结构选择，不假设 Shopify 主题应用块会自动显示在自建店面。
- 使用本店真实商品 ID，单页切换商品时清理旧评论实例；空评价显示真实空状态，不编造买家、评价、评分或已验证购买标记。
- 评论提交成功不等于公开，按后台审核状态验收；发送邀评邮件前明确受众、触发条件与通知配置。
- SEO 使用真实已发布评价，合并现有 Product 结构化数据，避免重复冲突；API 或组件的存在不保证搜索结果展示星级。
- 官方指南说明 `@customerssay/react` 尚未公开发布，不能假设可直接从公共 npm 安装。实施时重新核对。

### Sectionly B2B Wholesale

- 读取实际商品规则、MOQ 和必填字段；使用本店商品及变体，不能让浏览器提交的价格或身份决定购买授权。
- 现成询价组件只负责询价；隐藏价格、加购限制与结账校验需由自建店面及服务端落实，不能把它描述为完整 B2B 账户/定价系统。
- 询价先保存，草稿订单异步创建；分别读回询价与 Shopify 草稿订单结果。重试同一询价保留原幂等键和请求内容，避免重复订单。
- 创建测试询价、草稿订单或发送通知前明确实际写入范围；安装请求不自动授权生成业务数据。

### 17TRACK 物流

- 区分站外查询链接、Shopify 应用和服务端 API 三种方式；先核对所装应用的 Headless 支持、收费、额度、承运商覆盖与数据权限。
- 订单号不等于运单号；使用真实履约运单与承运商信息，不能伪造运输事件或把“查询不到”写成“未发货”。
- 若接入 API/通知/Webhook，依据当前官方契约落实服务端凭据、回调校验与重试；私有订单和收件人信息不得通过公开查询接口泄露。
- 物流查询服务不代表承运、时效保证、退款或理赔能力；仅展示本站真实可提供的服务。

## 本项目服务端接入约定

- 2026-11-16 用户确认代发由本站自己的仓库发货。以 Shopify 原生商品/图片、库存、采购订单和履约作为业务事实来源；扩展资料优先用合适访问范围的 Metafields/Metaobjects，避免为相同数据建立额外数据库。新增定义仍先明确类型、归属、用途与访问范围并取得具体写入授权。Shopify Files 的公开访问属性与询价私有附件需求分别核实；授权凭据、持久任务和重试能力单独评估，不能仅因 Shopify 能存商品就宣称自动同步已成立。
- 多规格批量购买沿用 Shopify 购物车，规格区提供 Bulk Buy 弹窗；公开 SKU 按需分页，不通过询价接口取购买数据。服务端校验最多 250 个不同规格、每行 1–9999 整数，仅转发规格 ID 与数量，不信任浏览器价格。实际价格/库存由 Shopify 决定；警告和失败保留用户输入，不自动重试加购。
- 商品页批发购买按钮下提供 More Shipping Options 弹窗，使用所选 SKU/数量和用户填写的配送国家、州省、城市、邮编及街道向 Shopify 查询当前已配置的固定运费。使用独立临时购物车，不替换用户购物车，不创建订单、不发送通知、不保存客户地址簿；地址通过 POST 发送，响应 private/no-store/noindex，不回传购物车 ID、地址或结账凭据，不写 URL/分析。目的地限本站已开放市场；美国/加拿大/澳大利亚/日本的州省使用 Shopify 代码与可见名称下拉，其余市场按地址必需项提交；输入变化立即失效旧结果，错误保留输入。费用仅针对本商品/数量，不含其他购物车商品、税费或结账调整；无配送方式与服务故障分别提示，不能推算参考运费/时效。当前店铺无承运商账户，本阶段仅查 Shopify 固定配送选项，不将其描述为承运商实时报价。
- 商品页标题上方提供 Wholesale / Dropshipping / Customization 三种模式，默认批发；切换保留当前 SKU，批发保留数量、真实单价及购买流程。询价入口放在单价右侧，使用至少 44px 高的有色边框按钮；数量阶梯只在批发模式显示。定制模式显示七步流程、定制申请和买样品入口；买样品将当前规格的 1 件普通商品加入购物车，定制样品另行报价。代发货模式目前仅通过现有询价收集合作需求，不宣称已支持 Shopify 商品同步、订单自动履约或无品牌包装；这些能力另行核实开发。所有模式不自动修改价格、折扣、库存、运费或 MOQ。
- 三模式共用现有 Sectionly 询价，服务类型通过 note 保存，保留 Wholesale/OEM/ODM，增加 Dropshipping/Customization；不新增第三方接口。桌面弹窗采用商品摘要、服务类型、需求、联系信息的顺序，联系字段双列、手机单列。
- 联系方式必须填写：询价邮箱及电话/WhatsApp 均必填，姓名/公司、详细需求及后台必填项保留。电话在前端和服务端校验，保存到应用的自定义字段；样品链接和目的地可选。当前 B2B 官方公开 Headless 契约及表单脚本未提供附件上传能力，不展示无法保存的上传控件，明确提供邮件补充附件入口；不据此断言供应商内部没有其他接口。参考站服务时效、联系身份和 Trustpilot 评分不得复制到本站。
- 评价入口保留标题下紧凑摘要和详情导航锚点，完整评价位于详情图后；使用简洁标题、真实评价数及明确的写评价按钮。零评价/接口失败不得填充示例评分。

- 已确认使用本站 React 界面与服务端代理，不把应用后台或主题应用块嵌入商品页。`app/lib/business-tools.server.js` 负责固定目标的 API 调用、校验及错误处理；对应资源路由只返回必要公开字段，私人结果使用 private/no-store，不加入 sitemap。
- 本地配置候选变量为 `CUSTOMERSSAY_SECRET_KEY` 与 `SECTIONLY_B2B_PRIVATE_KEY`，均不带 PUBLIC 前缀；实际创建/保存须按根规则另获具体授权。本规则不包含凭据值。
- 访客会话与防跨站提交令牌仅在资源接口按需建立，避免将私人令牌写入可共享缓存的商品 HTML。官方确认 Oxygen 的 `oxygen-buyer-ip` 由托管平台提供；仅在实际 Oxygen 入口使用，不信任任意 X-Forwarded-For 或浏览器提交的顾客 ID。
- 评论图片使用签名、限时的本站代理，仅接受已核对的应用/公共存储域名；不开放任意 URL 代理。新增媒体域名先核对来源，未验证的域名不放行。公开评论只返回昵称、正文、评分、日期及图片，不暴露邮箱、顾客 ID 或私人互动信息。
- 本轮仅接通既有通用询价入口，保留零售购买；读取 B2B 商品归属规则不自动启用后台的隐藏价格、隐藏购买按钮或结账限制。
- 公开首屏评分可优先读取应用同步的 Shopify 标准评分/Customerssay 汇总元字段，完整评价仍读取应用 API。未配置、接口失败与真实零评价分别显示。

- 用户后续要求三模式每个按钮、后续页面与业务结果完整对齐，不能以询价代替代发系统或以邮件代替站内附件。当前三模式界面仅为阶段草稿；完整范围及跨系统方案统一维护在[既有接入方案](../plans/2026-11-13-reviews-b2b-integration.md#三模式完整流程方案)，用户于 2026-11-16 已确认推进，受限操作仍按根授权边界执行。
