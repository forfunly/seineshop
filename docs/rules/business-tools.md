# 评价、B2B 询价与物流工具

本文件保存 Seine Shop 已选用业务工具、官方资料和接入要求；属于 `docs/rules/` 的长期规则，英文 kebab-case 命名，不保存凭据、不导入前台、不自动清理。安装和验收事实统一记录在 [项目状态](../project-state.md)，不以本文件推断已安装或已上线。

## 选用范围与任务入口

用户于 2026-11-12 明确要求将以下三类工具安装到 Seine Shop，供后续业务使用。安装目标仅为 `ps83if-c4.myshopify.com`，操作前核对后台店名与域名。

| 任务命中条件 | 选用工具 | 实施前必读资料 |
| --- | --- | --- |
| 商品/店铺评价、星级、图片或视频评论、邀评、评论结构化数据 | Customerssay.ai Reviews | [Shopify 应用页](https://apps.shopify.com/customerssay-ai-reviews-app?locale=zh-CN)、[Reviews Headless 接入指南](https://docs.sectionly.ai/zh/reviews/headless) |
| 批发询价、最低起订量 MOQ、多 SKU 询价清单、询价转草稿订单 | Sectionly B2B Wholesale | [B2B Headless 接入指南](https://docs.sectionly.ai/zh/b2b/headless)、[官方登录与安装入口](https://b2b.sectionly.ai/)；填写本店域名后进入 Shopify 授权页 |
| 包裹查询、运输状态、物流异常、订单跟踪通知 | 17TRACK | [正式 Shopify 应用页](https://apps.shopify.com/17track)、[用户提供的物流说明页](https://www.17track.net/en/carriers/track-your-parcel)、[17TRACK API 官方资料](https://api.17track.net/en/doc) |

- 两份 Sectionly Headless 文档是接入指南，不是两个额外应用；Reviews 指南对应 Customerssay，B2B 指南对应独立的 Sectionly B2B Wholesale。
- 用户提供的 17TRACK 链接是针对 Track Your Parcel 的物流说明页，不是应用安装地址，也不表示本站使用该承运商。不得据此固定所有订单的承运商。
- 2026-11-12 已核验三款应用在本店安装且后台可打开；验收与未配置项见 [项目状态](../project-state.md)。后续仍需重新核验，不把后台安装视为 Hydrogen 集成完成。
- 相关任务先读取本文件，再实际读取所需官方文档的最新正文；不要仅凭链接或本次摘要编写接口。优先复用这些已选工具，新增替代工具或重复接入前先说明原因。

## 安装与凭据

- 当前会话的安装请求覆盖上述三类应用的安装准备与执行；费用、实际数据权限和 Headless 兼容性以安装页核验为准。出现付费订阅时先说明金额、周期与套餐并取得批准；需要确认敏感数据访问或法律协议时，在具体安装确认页说明范围并请求确认。
- 本文件仅记录选用决定，不为将来会话自动批准凭据、环境配置、客户通知、商品或订单变更、前台发布。继续遵守 [根授权边界](../../AGENTS.md#授权边界)。
- 浏览器登录、多因素验证和安全挑战由用户完成；不得通过提取浏览器 Cookie、会话或未公开安装接口绕过授权流程。
- Reviews 和 B2B 的店面密钥相互独立；浏览器公钥限制真实 Origin，私钥只保存在获授权的服务端配置中。创建或变更密钥与 `.env` 前按根规则确认具体范围，不在文档、聊天、日志或构建中记录私钥。
- 分别记录“已选用”“后台已安装”“Headless 已接入”“生产已验证”；安装成功不能代替前台接入验收。未见后台成功状态时只写“待安装/未核实”。

## Hydrogen 接入要求

### Customerssay 评价

- 支持现成 JS 组件、自定义 API 界面和服务端渲染；结合现有 Hydrogen 结构选择，不假设 Shopify 主题应用块会自动显示在自建店面。
- 使用本店真实商品 ID，单页切换商品时清理旧评论实例；空评价显示真实空状态，不编造买家、评价、评分或已验证购买标记。
- 评论提交成功不等于公开，按后台审核状态验收；发送邀评邮件前明确受众、触发条件与通知配置。
- SEO 使用真实已发布评价，合并现有 Product 结构化数据，避免重复冲突；API 或组件的存在不保证搜索结果展示星级。
- 官方指南说明 `@customerssay/react` 尚未公开发布，不能假设可直接从公共 npm 安装。实施时重新核对。

### Sectionly B2B Wholesale

- 读取实际商品规则、MOQ 和必填字段；使用本店商品及变体，不能让浏览器提交的价格或身份决定购买授权。
- 现成询价组件只负责询价；隐藏价格、加购限制与结账校验需由自建店面及服务端落实，不能把它描述为完整 B2B 账户/定价系统。
- 询价先保存，草稿订单异步创建；分别读回询价与 Shopify 草稿订单结果。重试同一询价保留原幂等键和请求内容，避免重复订单。
- 创建测试询价、草稿订单或发送通知前明确实际写入范围；安装请求不自动授权生成业务数据。

### 17TRACK 物流

- 区分站外查询链接、Shopify 应用和服务端 API 三种方式；先核对所装应用的 Headless 支持、收费、额度、承运商覆盖与数据权限。
- 订单号不等于运单号；使用真实履约运单与承运商信息，不能伪造运输事件或把“查询不到”写成“未发货”。
- 若接入 API/通知/Webhook，依据当前官方契约落实服务端凭据、回调校验与重试；私有订单和收件人信息不得通过公开查询接口泄露。
- 物流查询服务不代表承运、时效保证、退款或理赔能力；仅展示本站真实可提供的服务。
